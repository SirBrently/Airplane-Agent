How to Install in Webflow — 4 steps

  1. 1
    Log in to webflow.com and open the gojetswest.com project.
  2. 2
    In the left sidebar, click the ⚙ (Settings) icon, then navigate to Custom Code.
  3. 3
    Scroll to the "Footer Code" section (labeled "Before </body> tag"). Paste the entire widget code from Section 4 below into that box.
  4. 4
    Click Save Changes, then go to Publish → Publish to gojetswest.com. Sophie will appear in the bottom-right corner within seconds.
Tip: If you want to test on a single page first before site-wide publish, open any page in the Webflow Designer → Page Settings → Custom Code → paste into the "Before </body> tag" field for that page only.
